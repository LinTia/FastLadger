## 复现材料

| 文件 | 用途 |
|---|---|
| [reproduce_review.py](reproduce_review.py) | 仅使用 Python 标准库，提取原文 SQL 并重放明确的算法/协议反例 |
| [verification-results.json](verification-results.json) | 本轮实际运行的 16 个反例结果，包含输入语义、实际与预期结果、证据类型和 SQLite 版本 |
| [findings.json](findings.json) | 18 项发现的结构化数据，方便其他 AI 按编号处理 |

在与审查基线相同的仓库根目录运行（Python 3.10+）：

```bash
python3 gpt/reproduce_review.py --repo . --json gpt/verification-results.json
```

脚本不会修改业务数据库或仓库源文件；上面的 `--json` 会更新指定结果文件。
其中断言用于证明被审查版本的反例能够出现，不是健康应用的功能测试。修复后需要重新审核这些反例，并将它们转为正式实现的回归测试。
