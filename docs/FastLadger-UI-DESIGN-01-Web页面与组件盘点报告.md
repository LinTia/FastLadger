## 3. 逐页盘点（17 个路由级视图；§3.6 为对话框专题、§3.18 为壳层，均不计入视图计数）

> 每页按 6 个维度给出。差异等级：**A**=结构性不符（需重构布局）/ **B**=样式不符（令牌/组件替换即可）/ **C**=能力未覆盖（缺状态或入口）/ **D**=现状需保留。

### 3.1 登录页 / 注册页（`renderLogin`，app.js L161–231）—— 计 2 个视图

1. **路径/组件/样式入口**：`#view` 内单卡；`card.style.maxWidth=380px`、`margin=48px auto`（L168–169 内联）；样式入口 `.card` + 内联 cssText。
2. **与规范差异**：**B** — 无品牌区结构（emoji 📒 作 logo，L172）；卡片直角感与规范 14px 圆角/边框层级不符；无深色主题；无错误态区域（错误仅 toast）；副标题"家庭智能记账 · 截图秒记"沿用旧定位文案。
3. **不可删除功能**：用户名/密码登录；注册（用户名 + 密码 + 确认密码，`minLength=8`，L181）；注册成功自动登录（L193–199）；登录/注册互相切换（L220–228）；按钮 pending 文案（L207）。
4. **依赖**：`POST /auth/login`、`POST /auth/register`；成功后写 `localStorage.fl_token` / `fl_whoami`；401 统一清会话（L105–109）。无权限概念。
5. **手机/桌面**：手机端为唯二可达页面（另一为底栏体系），需按规范改为**移动优先单列 + 44px 触控 + 软键盘不遮挡提交**；桌面端需居中卡片 + 品牌区，不得超过 400px 宽。
6. **IA 结论**：无。

### 3.2 账本列表（`renderBooks`，L234–303）

1. **路径/组件/样式**：`.card.book-list`（L238）；行结构 `div` 内联 flex（L257–258）；`.empty`（L243）。

#### 7.2.2 原生控件策略（响应 UIREV-06）

**原则：`<select>` / `<input type=date>` 不追求"数量归零"。** 自定义控件不天然优于原生控件；无等价可访问性证据的替换属于降级。逐场景决策：

| 场景 | 现状 | 决策 | 理由 |
|---|---|---|---|
| 交易筛选：类型 / 账户 / 分类 | 原生 `<select>` | **优先保留原生**，仅在"需要图标列/分组/长文本省略"时升级 | 选项多、需快速键盘选择（首字母跳转）、移动端系统滚轮体验稳定 |
| 记一笔：分类选择 | 原生 `<select>` | **升级为分组选择器**（网格/分组 + 搜索） | 分类有父子层级，原生 select 无法表达层级与图标；要求同时提供键盘方向键导航 + `role=listbox` + `aria-activedescendant` |
| 记一笔 / 编辑：账户 | 原生 `<select>` | **可保留原生**（账户数通常 <20） | 有备用；若升级须同时实现键盘与读屏 |
| 日期（记一笔、编辑、筛选、导出） | `<input type=date>` | **保留原生** | 系统日期选择器自带本地化、日历键盘操作、读屏支持；自研难以等价 |
| 月份（报表） | 两个按钮（本月/上月） | 升级为月份切换控件，**保留键盘左右键 + 明确 `aria-label`** | 现状无自定义区间能力 |
| 预算类型 / 投资类型 / 账户类型 | 原生 `<select>` | 保留原生 | 选项少、无层级 |
| 每页条数、分页 | 按钮 | 保持按钮 | 无需控件 |

**验收（不再以数量归零为准）**：
1. 每个被替换的控件，必须提交 **键盘可达**（Tab 进出、方向键选择、Escape 关闭）、**读屏可达**（`role`/`aria-*`/可读名称）、**焦点可见**、**移动端触控 ≥44px**、**日期本地化**五项证据；缺任一项即回退原生。
2. 每个保留原生的控件，在清单中记录"保留原因"，并验证外观与主题协调（统一高度/边框/焦点环，必要时用 `appearance` 与包装层统一，但**不替换语义**）。
3. 全站控件清单（保留 / 替换）+ 逐项证据，作为 03 的交付物之一。

- 迁移策略：先新建组件、再逐页替换，**每页替换后跑一次 44px 触控与无溢出检查**；不允许一次性删除所有内联样式。
