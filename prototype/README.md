# FastLedger 可交互原型

完整的前端可交互原型，覆盖 13 个核心页面，演示数据保存在浏览器本地（localStorage）。**已移除全部第三方遥测脚本，零外部请求、可完全离线运行。**

## 运行方式

```bash
# 在本目录（prototype/）下启动任意静态服务器
python3 -m http.server 8765
```

然后浏览器打开 http://localhost:8765/ ，演示账号已预填（me / 123456），直接点登录。

## 页面清单（13 个）

登录、首页账单、截图识别记账、手动记账/转账、交易详情、账户、两级分类、投资资产、预算、报表、导出、家庭成员、我的设置。

> 其中"分类管理""数据导出""家庭成员""设置"等入口在底部"我的"页（`/profile`）的二级菜单中。

## 说明

- 原型为纯前端演示，不包含真实后端；控制台中与后端 API 相关的报错（如 time offset、app info）属正常现象，不影响页面交互。
- 数据在各页面间实时联动：记一笔后，首页、报表、预算、资产会同步更新。
- **本目录由在线原型导出为本地静态资源（构建产物快照），仓库内暂无可编辑的工程源文件**；如需调整交互，可在在线原型中修改后重新导出。
- 已确认无任何外部域名请求（slardar / tea 等监控脚本均已删除）。
