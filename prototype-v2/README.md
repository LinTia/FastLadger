# FastLedger 新版可交互原型（依设计规范 v1.0 构建）

本原型是 `docs/FastLedger-Web设计规范.md` 的可运行示范：单文件 `index.html`、零外部请求、可完全离线打开（双击即可，或任意静态服务器）。

## 覆盖页面（12 视图）

登录、首页账单（概览三卡 + 按日分组 + 筛选）、记一笔（支出/收入/转账分段切换 + 必填校验）、截图识别（端侧 OCR → 规则解析 → LLM 兜底三级漏斗演示 + 确认弹窗，**绝不自动入账**）、交易详情（编辑 / 删除二次确认 + 余额联动回滚）、账户（净资产汇总）、两级分类、预算（正常/接近/超支三态）、报表（近 6 月趋势柱状 + 分类占比环形图）、我的（菜单中枢）、家庭成员（角色徽标 + 可见性开关 + 常驻隐私提示）、数据导出（筛选 + 预览）、设置（API Token 生成/撤销、备份状态）。

## 交互说明

- 移动端（<640px）显示底部 Tab（中央"记一笔"凸起按钮），桌面端显示顶部导航；同一套设计 token。
- 演示数据存 `localStorage`（键 `fl_v2_state`），各页面实时联动：记一笔 → 首页/账户/预算/报表同步更新；删除 → 余额回滚。
- 全部颜色/圆角/阴影/动效引用规范 token；`prefers-reduced-motion` 下动画关闭。

## 与 `prototype/`（旧版快照）的关系

`prototype/` 是在线原型的构建产物快照（本规范与本文档主题 token 的取证来源），保留不动；`prototype-v2/` 是依据规范手写重建的参考实现，后续 Web 端（`server/web/dist/`）与 Flutter 主题以规范为准对齐。
